# Форма заявки: таблица Google и письма Илане

Пока адрес не задан, форма на главной открывает WhatsApp на номер Иланы со всеми полями заявки. Это работает уже сейчас. Чтобы заявки ещё и копились в таблице, а Илана получала письмо о каждой, нужен скрипт Google Apps Script из `integrations/lead-form/`. Всё делается в аккаунте Google клуба, кода писать не нужно.

Отмечайте галочками.

## 1. Таблица

- [ ] Открыть https://sheets.google.com под аккаунтом клуба → **Пустая таблица**. Назвать, например, `Заявки с сайта`.
- [ ] Лист и заголовки создавать не нужно: при первой заявке скрипт сам заведёт лист `Leads` с колонками `time, lang, hall, hall_name, name, phone, who, age, message, status`.
- [ ] Доступ к таблице дать только тем, кто обрабатывает заявки (Поделиться → по почте). Публичную ссылку не включать.

## 2. Скрипт

- [ ] В таблице: **Расширения → Apps Script**.
- [ ] Удалить всё в `Code.gs` и вставить содержимое файла `integrations/lead-form/Code.gs` из репозитория.
- [ ] Шестерёнка слева (**Настройки проекта**) → включить «Показывать файл манифеста appsscript.json». Открыть `appsscript.json` в редакторе и заменить его содержимым файла `integrations/lead-form/appsscript.json` (там часовой пояс Израиля и настройки веб-приложения).
- [ ] Сохранить (значок дискеты).

## 3. Кому приходят письма

Почта получателя в коде не хранится, её задают в свойствах скрипта.

- [ ] **Настройки проекта → Свойства скрипта → Добавить свойство**:
  - `NOTIFY_EMAIL`: почта Иланы (или общая почта клуба), на неё приходит письмо о каждой заявке.
  - `DIGEST_EMAIL` (по желанию): куда слать ежедневную сводку. Если не задано, сводка идёт на `NOTIFY_EMAIL`.

В письме: имя, телефон, для кого и возраст, зал, сообщение и ссылка `wa.me`, чтобы сразу написать человеку в WhatsApp.

## 4. Публикация как веб-приложение

- [ ] Справа вверху **Начать развертывание → Новое развертывание**. Тип (шестерёнка): **Веб-приложение**.
  - Описание: `Форма сайта`
  - Запуск от имени: **Я** (аккаунт клуба)
  - У кого есть доступ: **Все** (Anyone). Без этого сайт не сможет отправить заявку; читать таблицу это никому не позволяет.
- [ ] **Развернуть** → Google попросит разрешения (таблица, отправка почты) → разрешить под аккаунтом клуба. Если появится «Приложение не проверено»: Дополнительно → перейти к проекту.
- [ ] Скопировать **URL веб-приложения**. Он выглядит так: `https://script.google.com/macros/s/…/exec`.

## 5. Адрес в сайт

- [ ] В репозитории в `content/site.json`, в блоке `contact`, вписать адрес в `"lead_endpoint": ""`, между кавычками.
- [ ] `npm run gen`, затем коммит и пуш в `main` (или попросить того, кто обновляет сайт). После деплоя кнопка формы называется «Отправить», а не «Отправить в WhatsApp».
- [ ] Проверить: отправить заявку с сайта со своим номером → в таблице появилась строка, на `NOTIFY_EMAIL` пришло письмо. Тестовую строку удалить.

## 6. Ежедневная сводка (по желанию)

- [ ] В редакторе скрипта выбрать функцию `setupDigest` в списке сверху → **Выполнить**. Каждый день в 20:00 по Израилю на `DIGEST_EMAIL` придёт список заявок, у которых в колонке `status` всё ещё `new`.
- [ ] Обработав заявку, впишите в `status` что угодно другое, например `позвонили`, и она пропадёт из сводки.
- Отключить: значок будильника слева (**Триггеры**) → удалить триггер `dailyDigest`.

## Если код скрипта изменился

Вставить новый `Code.gs`, затем **Начать развертывание → Управление развертываниями → карандаш → Версия: Новая версия → Развернуть**. Адрес остаётся тем же, в сайте ничего менять не нужно.

## Как это устроено

- Сайт отправляет заявку обычным POST-запросом. Ответ Apps Script браузеру не виден (Google не разрешает такие ответы чужим сайтам), поэтому сайт считает заявку отправленной, если запрос дошёл. Если сеть подвела, человеку сразу показывается кнопка WhatsApp с той же заявкой.
- Скрытое поле-ловушка отсекает ботов: такие заявки не записываются.
- Скрипт заново проверяет телефон (израильский номер), возраст, согласие с политикой конфиденциальности и длину полей. Значения, начинающиеся с `=`, `+`, `-` или `@`, записываются как текст, чтобы таблица не приняла их за формулу.
