# Панель тренеров: настройка

Панель живёт по адресу https://unifight-haifa.com/admin/. Тренера входят в неё через Google или открывают из Telegram и сами правят свою карточку, фото и расписание, на трёх языках. Шаги 1–6 владелец делает один раз, дальше только добавляет тренеров (шаг 7).

Ключи и пароли никогда не пишите в чат, в репозиторий или в описание коммита. Каждый секрет сохраните отдельным файлом в папку `private/secrets/` в папке проекта на компьютере, где работает ассистент, и просто напишите в чат, что файл на месте.

## 1. Cloudflare

1. Зарегистрироваться на https://dash.cloudflare.com на почту клуба. Домен переносить не нужно: панель работает на адресе `unifight-panel.….workers.dev`.
2. Справа вверху значок профиля → **My Profile** → **API Tokens** → **Create Token**.
3. Шаблон **Edit Cloudflare Workers** → **Use template**.
4. В **Permissions** нажать **+ Add more** → `Account` · `D1` · `Edit`.
5. **Continue to summary** → **Create Token** → скопировать токен (он показывается один раз).
6. На главной странице аккаунта: **⋯** рядом с названием аккаунта → **Copy account ID**.

База D1 и сам сервис ассистент создаст и запустит сам.

**Что передать ассистенту:** файлы `private/secrets/cloudflare-token` и `private/secrets/cloudflare-account-id`.

## 2. GitHub App

Удобнее с компьютера: в конце скачивается файл.

1. https://github.com/organizations/Unifight-haifa/settings/apps → **New GitHub App**.
2. **GitHub App name**: название клуба, например `unifight-haifa`. Коммиты из панели будут подписаны `<название>[bot]`. **Homepage URL**: `https://unifight-haifa.com`.
3. **Webhook**: снять галочку **Active**.
4. **Repository permissions**: **Contents** → `Read and write`, **Actions** → `Read-only`, **Metadata** → `Read-only`. Остальное не трогать.
5. **Where can this GitHub App be installed?** → **Only on this account** → **Create GitHub App**.
6. Вверху страницы записать **App ID**.
7. Ниже **Generate a private key**: скачается файл `.pem`.
8. Слева **Install App** → **Install** → **Only select repositories** → `unifight` → **Install**. В адресе страницы в конце будет число: это Installation ID.

**Что передать ассистенту:** файл `.pem` положить в `private/secrets/github-app.pem`; App ID и Installation ID можно прислать в чат.

## 3. Ключ для перевода (Anthropic)

1. https://console.anthropic.com под почтой клуба, организация клуба.
2. **Settings** → **Limits**: поставить месячный лимит расходов, например $10. Перевод одной биографии стоит доли цента.
3. **Settings** → **API Keys** → **Create Key**, имя `unifight-panel` → скопировать ключ.

**Что передать ассистенту:** файл `private/secrets/anthropic-key`.

## 4. Вход через Google

1. https://console.cloud.google.com под аккаунтом клуба → новый проект, например `Unifight panel`.
2. **APIs & Services** → **OAuth consent screen**: тип **External**, название клуба, почта клуба.
3. Scopes: только `openid email profile`. Больше ничего не добавлять.
4. Нажать **Publish app**, статус должен стать **In production**. Проверка Google для этих разрешений не нужна.
5. **Credentials** → **Create credentials** → **OAuth client ID** → тип **Web application**.
6. **Authorized JavaScript origins**: добавить `https://unifight-haifa.com` и `http://localhost:4321` → **Create**.
7. Скопировать **Client ID** (вида `…apps.googleusercontent.com`). Он не секретный.

**Что передать ассистенту:** Client ID — в чат.

## 5. Владельцы (OWNER_EMAILS)

Только эти аккаунты видят в панели раздел «Доступ» и могут добавлять тренеров. Выдать это право из самой панели нельзя.

1. Создать файл `private/secrets/owner-emails`.
2. Вписать свою почту gmail (если несколько, через запятую, без пробелов).

**Что передать ассистенту:** файл `private/secrets/owner-emails`.

## 6. Бот панели в Telegram

Это новый, отдельный бот. Бот новостей в n8n остаётся как есть.

1. В Telegram открыть @BotFather → `/newbot`.
2. Имя, например `Unifight панель`, и адрес бота, оканчивающийся на `bot`.
3. BotFather пришлёт токен → сохранить его в файл.
4. `/mybots` → выбрать бота → **Bot Settings** → **Configure Mini App** (Main Mini App) → **Enable Mini App**.
5. Адрес: `https://unifight-haifa.com/admin/?tg=1`.

**Что передать ассистенту:** файл `private/secrets/tg-panel-bot-token`.

## 7. Добавить тренера

Первыми подключаем Илану и Натанэля, остальных потом.

1. Открыть https://unifight-haifa.com/admin/ → **Войти через Google** (своей почтой из шага 5).
2. Раздел **Доступ** → вписать gmail тренера.
3. Выбрать тренера из списка и роль: **тренер** (только свои карточка, фото и расписание) или **редактор** (все тренера и расписания). Редакторы: Илана, Александр, Натанэль.
4. Сохранить и отправить тренеру ссылку на панель.
5. Убрать доступ: **Отозвать** рядом с почтой. Действует сразу и отвязывает Telegram этого тренера.

## 8. Для тренеров: как пользоваться

1. Открыть https://unifight-haifa.com/admin/ → **Войти через Google**.
2. Выбрать, что править: биография, фото, расписание, отмена или перенос занятия.
3. Писать на одном языке, нажать **Перевести**.
4. Проверить два других языка, поправить, если нужно → **Сохранить**.
5. Статус: «Публикуется…», затем «На сайте» (около 3 минут) или «Не опубликовано» с причиной.
6. Telegram: в браузере **Подключить Telegram** → нажать ссылку, откроется бот → в панели внутри Telegram ввести 6 цифр, которые показаны на странице в браузере (код живёт 10 минут). Дальше панель открывается кнопкой «Панель» в боте без кода.
7. После этого панель открывается из кнопки меню бота, без входа через Google.

## 9. Если что-то не так

- «Не опубликовано»: сайт не собрался. Пока это не исправлено, не выйдут и следующие правки, поэтому сразу напишите владельцу или ассистенту: они исправят прямым коммитом.
- «Кто-то изменил это раньше вас — обновите»: обновите страницу, проверьте текст и сохраните ещё раз.
- Тренер ушёл или потерял телефон: **Доступ** → **Отозвать**.

## Как это устроено

Панель — маленький сервис Cloudflare Worker на адресе workers.dev. В его базе D1 хранятся список доступа и привязки Telegram, в репозитории ничего этого нет. Каждое сохранение — один коммит в `main` от GitHub App клуба, после него сайт пересобирается как обычно. Почты, Telegram id и ключи не попадают ни в репозиторий, ни в коммиты.
