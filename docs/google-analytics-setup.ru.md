# Google Analytics и Search Console: настройка

Пока идентификатор GA не задан, сайт не показывает баннер и ничего не грузит с Google. Всё включается двумя переменными репозитория, правка кода не нужна. Названия пунктов в интерфейсе Google иногда меняются; если что-то не нашлось, ищите по смыслу.

Отмечайте галочками.

## 1. Ресурс GA4 и поток данных

- [ ] Открыть https://analytics.google.com под аккаунтом клуба.
- [ ] Администратор (шестерёнка внизу слева) → **Создать → Ресурс**.
  - Название: `Unifight Haifa`
  - Часовой пояс: **Израиль**, валюта: **ILS**
  - Дальше ответить на вопросы о бизнесе как угодно, на работу сайта это не влияет.
- [ ] Платформа: **Веб**. Поток:
  - URL сайта: `unifight-haifa.github.io` (протокол `https` выбран по умолчанию)
  - Название потока: `Сайт`
  - Улучшенную статистику оставить включённой.
- [ ] Скопировать **Идентификатор потока данных** (Measurement ID) вида `G-XXXXXXXXXX`. Он есть в Администратор → Сбор и изменение данных → Потоки данных → `Сайт`.
- [ ] Администратор → Сбор и изменение данных → **Сбор данных**: «Сигналы Google» **не включать**. В политике конфиденциальности сказано, что рекламные функции выключены.

Код Google Tag со страницы потока («Инструкции по установке тега») вставлять никуда не нужно: сайт подключает его сам и только после согласия посетителя.

## 2. Идентификатор в GitHub

- [ ] GitHub → репозиторий `unifight` → Settings → Secrets and variables → Actions → вкладка **Variables** → **New repository variable**.
  - Name: `PUBLIC_GA_ID`
  - Value: `G-XXXXXXXXXX`
- [ ] Actions → **Deploy to GitHub Pages** → Run workflow (или любой пуш в `main`).

Почему переменная, а не секрет: идентификатор всё равно виден в коде каждой страницы, скрывать нечего. Если хочется именно секрет, заведите `PUBLIC_GA_ID` во вкладке **Secrets** и в `.github/workflows/deploy.yml` замените `vars.PUBLIC_GA_ID` на `secrets.PUBLIC_GA_ID`.

Значение проверяется при сборке: если оно не похоже на `G-…`, деплой упадёт с понятной ошибкой. Чтобы выключить аналитику, удалите переменную и перезапустите деплой.

## 3. Проверка

- [ ] Открыть сайт в режиме инкогнито. Внизу появляется баннер с кнопками «Принять» и «Отклонить».
- [ ] Нажать «Принять», походить по сайту, нажать кнопку WhatsApp.
- [ ] GA → Отчёты → **В реальном времени**: через минуту-две там видно посещение и событие `whatsapp_click`.
- [ ] Ссылка «Настройки cookie» внизу страницы снова открывает баннер.

## 4. Ключевое событие `whatsapp_click`

Главная цель сайта — чтобы родители написали в WhatsApp, поэтому `whatsapp_click` отмечаем как ключевое событие (бывшая «конверсия»).

- [ ] Администратор → Показ данных → **Ключевые события** → **Новое ключевое событие** → имя `whatsapp_click` → Сохранить. Так можно сделать сразу, не дожидаясь первого клика.
- [ ] Через сутки проверить в Администратор → Показ данных → **События**, что у `whatsapp_click` включён переключатель «Отметить как ключевое событие».

## 5. Параметры событий в отчётах

Чтобы видеть, например, с какой кнопки и для какого зала написали в WhatsApp, параметры надо зарегистрировать.

- [ ] Администратор → Показ данных → **Специальные определения** → **Создать специальный параметр**, область действия **Событие**. По одному на каждый параметр: `placement`, `venue`, `language`, `network`, `provider`, `channel`, `grade`, `to`, `method`. Название параметра в отчёте можно дать любое, «Параметр события» должен совпадать точно.

Какие события отправляет сайт:

| Событие | Когда | Параметры |
|---|---|---|
| `whatsapp_click` (ключевое) | кнопка WhatsApp | `placement`: `first_class`, `contact`, `schedule`, `schedule_none`, `lead_done` (после формы заявки), `venue_group` (группа зала); `venue` — зал, если кнопка в карточке расписания или зала |
| `phone_click` | номер телефона | `placement` |
| `social_click` | Facebook, Instagram | `network` |
| `schedule_filter` | фильтр расписания | `grade` (`-1` = все, `0` = сад) или `venue` (`all` = все) |
| `map_open` | кнопка карты, Google Maps, Waze, транспорт | `provider`: `osm`, `google_maps`, `waze`, `transit`; `venue` |
| `language_switch` | переключатель языка | `to` — язык, на который переключили |
| `schedule_view` | расписание показалось на экране, или выбрали другой зал | `venue` (`all` = все залы) |
| `lead_submit` | отправлена форма заявки | `venue` (`none` = не выбран), `method`: `form` (в таблицу) или `whatsapp` (адрес формы не задан) |
| `news_share` | кнопки «Поделиться» в новости | `channel`: `whatsapp`, `facebook`, `telegram`, `copy`, `native` (системное меню «Поделиться» на телефоне) |

У каждого события есть ещё `language` — язык страницы.

## 6. Search Console

- [ ] Открыть https://search.google.com/search-console → **Добавить ресурс** → **Ресурс с префиксом в URL** → `https://unifight-haifa.com/`.
- [ ] Способ подтверждения: **HTML-тег**. Google покажет `<meta name="google-site-verification" content="…">`. Скопировать только значение `content`.
- [ ] GitHub → Variables → **New repository variable**: Name `PUBLIC_GSC_VERIFICATION`, Value — скопированное значение. Перезапустить деплой.
- [ ] Когда деплой закончится, нажать в Search Console **Подтвердить**. Тег стоит на главной странице ресурса (`/unifight/`), именно её Google и проверяет. Переменную после подтверждения не удаляйте: без тега подтверждение со временем слетает.
- [ ] Search Console → **Файлы Sitemap** → ввести `sitemap.xml` → **Отправить**. В карте сайта все страницы на трёх языках.
- [ ] Связать с GA: в GA Администратор → Связи с другими продуктами → **Связь с Search Console** → Связать → выбрать ресурс и поток `Сайт`.

`robots.txt` сайт тоже публикует, но поисковики читают его только в корне домена, поэтому на `github.io/unifight/` он не действует. После перехода на свой домен (см. [domain-switch.md](domain-switch.md)) он заработает сам, а в Search Console нужно будет добавить новый ресурс и снова отправить `sitemap.xml`.

## 7. Необязательно: срок хранения данных

По умолчанию GA4 хранит подробные данные о событиях 2 месяца. Политика конфиденциальности допускает до 14.

- [ ] Администратор → Сбор и изменение данных → **Хранение данных** → «Хранение данных о событиях»: **14 месяцев**, если нужны сравнения год к году. Иначе оставить 2.
